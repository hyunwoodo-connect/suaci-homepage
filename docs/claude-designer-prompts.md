## 브랜드
- 이름: SUACI (워드마크는 항상 소문자 "suaci". 절대 대문자 SUACI로 로고화하지 않는다)

- 슬로건: Calm your skin, wherever you are.
- 포지셔닝 한 문장: "좋아지게 만들기보다, 무너지지 않게."
- 카테고리: 단일 SKU 브랜드. 상품 리스트/카테고리 페이지 없음.

## 비주얼 디렉션 (이게 가장 중요)
- 일본 매거진 미감. 레퍼런스: POPEYE, &Premium, BRUTUS, Casa BRUTUS의 잡지 레이아웃.
- 흰 바탕, 넓은 여백, 단정한 그리드. 한국어 본문 옆에 작은 영문 캡션이 자연스럽게 얹히는 편집형 레이아웃.
- 한 화면에 보이는 정보는 적게. 비어있음을 두려워하지 않는다.
- 일반 쇼핑몰 톤 금지. 페이지가 카탈로그처럼 보이면 실패.

## 컬러 (엄격)
- Background: 흰색 (#FFFFFF 또는 따뜻한 화이트 #FAFAF7)
- Primary key color: 짙은 초록 (forest deep). 후보 hex 중 가장 깊고 차분한 톤 선택: #1A4D3A / #0F3D2E / #1F5C42
- Text: #1A1A1A (순수 #000은 너무 강함)
- Accent: 따뜻한 베이지 #F2EDE4 (보조 면, 거의 안 씀)
- **짙은 초록은 강조용**. 페이지를 도배하지 말 것. 점·줄·헤드라인의 한 단어·CTA 보더 등 좁은 면적에 등장할 때 가장 강하다. 전체 화면에서 초록의 차지 비율 10% 미만.
- 흰 바탕 면적이 전체의 70% 이상.

## 타이포그래피
- 한국어 본문: Pretendard, 행간 1.7~1.8, letter-spacing 0
- 영문 헤드/캡션: 모던 산세리프 (Inter Display, Manrope, Geist 같은 결)
- 영문 캡션은 작게. 한국어보다 키우지 않는다.
- 헤드라인은 large하되 굵게 가지 말 것. weight 400~500, size로 위계를 만든다.
- 숫자는 tabular-nums.

## 모션 (정적 디자인 산출물이라도 명세에 포함)
- Smooth scroll (Lenis 풍 부드러운 관성)
- Scroll-linked 모션 우선 — 한 번 트리거하고 끝나는 것보다, 스크롤 진행도에 묶인 모션
- 큰 헤드라인은 한 단어씩 페이드업
- Bouncy/스프링 금지. ease-out 위주, 600~1200ms
- 한 화면에 동시 모션 1~2개 이하
- 제품 컷은 미세한 호흡(부유) 또는 스크롤에 묶인 회전·페럴럭스

## 페이지 구조 (Home, 위에서 아래 순서)

1. **이벤트 배너 (상단 라인)** — 매우 얇음, 닫기 가능, 흰 바탕에 짙은 초록 텍스트 한 줄.
   카피 예시: "사전 알림 신청 시 출시 10% 할인 →"

2. **헤더** — 로고(소문자 suaci) + 우측 메뉴(Story / Product / Order) + 언어 토글(ko · en · ja · zh · th) + 작은 로그인 진입 아이콘. 헤더는 매우 얇게.

3. **Hero (풀스크린)**
   - 거의 비어있다. 짙은 초록 작은 점 하나 또는 작은 문자.
   - 메인 카피 (한 줄): "피부가 흔들리는 순간을 줄이는 일."
   - 서브 (작게, 영문):
     ```
     SUACI Daily Calming Mist
     No.01 — for skin that easily wavers.
     ```
   - 스크롤 유도는 작은 텍스트 "scroll" 또는 화살표 1개.

4. **Intro / 문제 제기**
   - Eyebrow (작은 영문): `No.01 — Why we made this`
   - 헤드: "피부는 매일, 조금씩 흔들립니다."
   - 본문 (행간 넉넉히, 짧은 호흡으로 줄바꿈):
     ```
     스트레스, 냉난방, 미세먼지, 자외선.
     땀, 마찰, 화장, 그리고 다시 외출.

     피부는 좋아질 시간보다,
     나빠질 수 있는 순간을 더 자주 만납니다.

     우리는 이 순간들을 줄이고 싶었습니다.
     좋아진다는 약속 대신,
     덜 무너지도록 돕는 일.
     ```

5. **Product 인트로 섹션**
   - 한 화면 통째로 제품컷(짙은 초록 미스트 보틀) 한 장. 왼쪽 또는 오른쪽 큰 면적.
   - 반대편에 작은 카피:
     - Eyebrow: `No.02 — Product`
     - 헤드: "손에 닿는 곳에 두는 진정."
     - 짧은 디스크립션:
       ```
       SUACI Daily Calming Mist는
       피부가 예민해지는 순간 가볍게 뿌리는,
       약산성·저자극 포터블 카밍 미스트.
       80ml.
       ```
     - 작은 링크: `제품 자세히 보기 →`
   - **할인가 표시 자리**: 정가에 취소선, 할인가 짙은 초록, 작은 할인율 뱃지. 매우 단정하게.

6. **4 Moments — 사용 시나리오**
   - 섹션 헤드: "피부가 흔들리는 네 가지 순간." (영문 보조: `Four moments to mist.`)
   - 4개 카드 그리드 (데스크탑 2×2 또는 4×1, 모바일 1열).
   - 각 카드: 작은 라벨(Indoor/On makeup/Outdoor/Minimal) + 한국어 카피 3줄
     ```
     Moment 01 — Indoor / 실내
     냉방과 난방을 오가는 사이,
     피부가 먼저 마릅니다.
     책상 위에 두고, 한 번씩.

     Moment 02 — On makeup / 화장 위
     당김, 답답함, 들뜸.
     지우지 않고도 가라앉힐 수 있도록.
     화장 위에 가볍게 한 번.

     Moment 03 — Outdoor / 외부
     땀, 햇빛, 마찰.
     열감이 가시기 전,
     얼굴 위로 가만히 뿌려둡니다.

     Moment 04 — Minimal / 간결한 루틴
     가방 안에 하나.
     무거운 케어 대신, 한 번의 미스트로
     하루의 마침표를 찍습니다.
     ```

7. **Key Qualities — 6 인덱스**
   - 섹션 헤드: `What's inside the bottle` + 부제 "여섯 가지 결."
   - 6개 항목을 인덱스 리스트형으로 (01 / 02 / ... 매거진식 번호):
     ```
     01  수분 진정 — Hydrating calm
         예민해진 피부 결을 차분히 가라앉히는 보습 베이스.

     02  편리성 — Effortless
         뚜껑 열고 두 번. 손에 묻지 않습니다.

     03  휴대성 — Portable
         가방 안에서 자리를 차지하지 않는 사이즈.

     04  열감 케어 — Cooling touch
         뜨거워진 피부 위에 가볍게 내려앉도록.

     05  약산성 — Mildly acidic
         피부와 닮은 pH 영역에서.

     06  저자극 — Low irritation
         매일 써도 무겁지 않게.
     ```

8. **Brand Story 진입 블록**
   - 짧은 텍스트 두 줄 + 큰 링크 한 개.
   - 카피:
     ```
     좋아지게 만들지 않습니다.
     ── SUACI 브랜드 노트.

     [Read the story →]
     ```
   - 클릭 시 /story 페이지로 이동.

9. **Order / Coming Soon CTA**
   - 헤드: "출시 알림."
   - 서브: "입고 일정을 메일로 알려드립니다."
   - 이메일 인풋 한 줄 + 짙은 초록 버튼 "이메일 등록".
   - 보조 캡션 (작게): "사전 알림 신청 시 출시 10% 할인."

10. **푸터**
    - 좌측: "SUACI" 워드마크 + "Calm your skin, wherever you are."
    - 메뉴 컬럼 3개: Brand (Story / Journal) / Product (Daily Calming Mist / Ingredients / How to use) / Help (FAQ / Contact / Shipping & Returns)
    - 하단 미세 라인: © SUACI. All rights reserved. · 이용약관 · 개인정보처리방침 · 사업자정보
    - 푸터 자체가 너무 회색지대가 되지 않도록, 흰 바탕에 얇은 짙은 초록 가로선 1개로 영역 구분.

## 추가 UI 요소 (필요 시 디자인에 포함)
- **로그인 모달**: 흰 바탕, 짙은 초록 보더의 인풋, 단정한 폼. "이메일 / 비밀번호 / 로그인" + 회원가입 링크.
- **장바구니 드로어**: 우측에서 슬라이드. 빈 상태일 때 카피: "비어있습니다."
- **언어 토글**: 점(·) 구분자로 ko · en · ja · zh · th. 현재 언어만 짙은 초록.

## 톤 절대 금지
- 이모지, 느낌표 (단정한 마침표만)
- 과장 어휘 ("혁신", "최고", "프리미엄", "솔루션", "비밀")

- 카드 안에 카드, 보더 안에 보더 같은 중첩 컨테이너

## 페이지 구조

1. **상단 — 제품 시각 영역**
   - 좌측: 제품컷 1장 (짙은 초록 미스트 보틀). 큼직하게. 흰 바탕 또는 따뜻한 베이지 배경.
   - 우측: 매우 단정한 정보 컬럼
     - 작은 영문 라벨: `No.01 — Daily Calming Mist`
     - 한국어 제품명: SUACI Daily Calming Mist
     - 한 줄 설명: "피부가 흔들리는 순간을 줄이는 휴대용 카밍 미스트."
     - 용량: 80ml
     - 가격 표시: 정가 38,000원 (취소선) / 할인가 34,200원 (짙은 초록) / -10% (작은 뱃지)
     - 옵션 선택 영역 (수량만)
     - CTA 버튼: `장바구니에 담기` (짙은 초록 보더, 흰 바탕, 호버 시 채워짐)
     - 보조 링크: `바로 구매` 텍스트만

2. **제품 상세 컷 — 슬라이드 또는 그리드**
   - 제품 다양한 각도, 사용 장면, 텍스처 컷.
   - 흰 바탕 위 큰 이미지들. 캡션은 작게 영문으로.

3. **에디토리얼 본문 — 잡지 기사처럼**
   - 섹션 헤드: "왜 이 미스트를 만들었나."
   - 본문 (이미 site-copy.md에서 발췌):
     ```
     좋아지게 만들기보다, 무너지지 않게.

     SUACI Daily Calming Mist는
     피부가 예민해지는 순간 가볍게 뿌리는,
     약산성·저자극 포터블 카밍 미스트입니다.

     크림이 아니라 미스트.
     가방 안에서, 책상 위에서, 운동 가방 안에서.
     ```

4. **4 Moments 미니 인덱스** (홈의 축약형)
   ```
   Indoor — 사무실에서, 마른 공기 위로
   On makeup — 화장 위, 당김이 시작될 때
   Outdoor — 외부활동 후 열감 위로
   Minimal — 가방 안 단 하나의 케어
   ```

5. **Key Qualities — 6개 (홈과 동일)**
   - 위 site-copy.md의 6개 키워드와 동일 사용.

6. **성분 / Ingredients 블록**
   - 헤드: "들어간 만큼만 말합니다."
   - 짧은 본문 + 전성분 리스트 (모노스페이스 폰트, 작게).
   - 전성분 자리는 임시: `정제수, 글리세린, 판테놀, 마데카소사이드, 알란토인, 베타-글루칸, [전성분은 추후 확정] ...`

7. **사용법 — 3단계**
   ```
   01  흔들지 않습니다.
   02  얼굴에서 약 20cm, 두세 번 가볍게 분사합니다.
   03  손대지 않고, 자연스럽게 흡수되도록 둡니다.
   ```

8. **연관 콘텐츠 (Story 진입)**
   - 작은 카드 한 개: 브랜드 스토리 페이지로 가는 링크.
   - "왜 우리가 이 미스트를 만들었나 → Read the story"

9. **푸터** (홈과 동일)

## UI 디테일
- 가격 표시는 매우 조용하게. 큰 빨간 할인율 뱃지 같은 일반 쇼핑몰 톤 금지.
- CTA 버튼은 외곽선 스타일 기본, 호버 시 짙은 초록으로 채워짐.
- 수량 selector는 미니멀 (− 1 + 형태).
- 좌측 제품 컷은 스크롤 시 sticky로 따라옴 (데스크탑만), 우측 정보가 스크롤되는 동안.

## 모션

- 가격은 카드처럼 튀어나오지 말 것 — 그냥 페이드.
- 4 Moments 인덱스는 스크롤 진행도에 따라 한 줄씩 페이드업.
