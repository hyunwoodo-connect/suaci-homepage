## 0. Voice & Tone — 카피 작성 지침

### 해야 할 것
- **짧게.** 한 호흡에 읽히는 문장. 두 문장 넘어가면 한 번 더 줄여본다.
- **현실적으로.** "좋아진다 / 해결된다 / 변한다"가 아니라, "흔들리지 않게 / 무너지지 않게 / 진정한다."
- **여백을 글에도.** 줄바꿈을 디자인 요소처럼 쓴다. 빽빽하게 채우지 않는다.
- **편집적인 디테일.** 한국어 본문 옆에 작은 영문 캡션, `No.01` 같은 번호, 부제 한 줄. 일본 매거진식 레이어링.
- **2인칭은 거의 안 쓴다.** "여러분의 피부", "당신의 일상" 같은 호명은 과한 톤. 관찰자 시점 / 1인칭 복수("우리는") 위주.

### 하지 말 것
- 과장 어휘: 혁신, 솔루션, 프리미엄, 완벽, 최고, 비밀.
- 의학·치료 단어: 치료, 회복, 개선, 효능, ~을 없애다.
- 느낌표. 물음표는 정말 필요할 때만.
- 이모지. 절대.

### 단어 사전 (이건 쓴다 / 이건 안 쓴다)
| 쓴다 | 안 쓴다 |
|---|---|
| 진정 | 치유 |
| 흔들림 / 무너짐 | 손상 / 트러블 |
| 덜어내다 / 가라앉히다 | 해결하다 / 없애다 |
| 가볍게 / 자주 | 강력하게 / 확실하게 |
| 컨디션 / 순간 | 효과 / 효능 |
| 손에 닿는 곳에 | 필수템 / 머스트해브 |

## 16. 작성자 노트 (다음 단계용)

- **법적 표현 체크.** "진정", "저자극", "약산성"은 표시·광고 심사 기준 상 대체로 허용. 다만 "치료", "회복", "개선"은 절대 미사용. 이 문서 카피는 그 룰에 맞춰 작성됨.
- **다국어.** 본 문서는 한국어 기준. en / ja / zh / th는 i18n 메시지로 분리 시 톤 매핑 별도 정의 필요. (특히 일본어는 같은 미니멀 톤을 직역하면 자칫 차가워짐 → 한 박자 부드럽게.)
- **카피 vs 디자인.** 디자인이 잡힌 뒤 길이가 안 맞는 문구는 줄인다. 늘리지는 않는다.
- **사진/영상 자리.** 카피 사이의 여백은 이미지가 채울 자리. 카피는 이미지의 존재를 가정하고 짧게 둔다.
